# Exact-root scope revision after shared prefix misses

[Report](REPORT.md), [protocol](PROTOCOL.md), [design](design.json),
[methods clarification](METHODS_NOTE.md), [held-out cases](heldout-cases.json),
[live responses](evidence/live-results.json), [analysis](evidence/summary.json),
and [reproduction](REPRODUCE.md).

The revision defines exact first-component equality and adds contrastive examples.
It reduced old scope's outside misses from 34/60 to 24/60 on fresh held-out cases,
three trials each. Pairing with unchanged main reduced conflict permission answers
from 9/69 to 7/69, with five supporting alarms and 21/21 incomplete-information
signals unchanged. Two new prefix cases were jointly accepted in every trial.
The revision helped incrementally but still violated the literal boundary contract.
Earlier results, main, deterministic authority and the default branch are preserved.
