# Next slices

## Implemented foundation

- Shared dependency-free decision engine, local rules, Jev/HTTP classifier contracts.
- Client/project configuration, immutable locks, reviewed project snapshots, pinned sessions.
- Six native adapter families, CLI/API integration, optional LiteLLM callback, Caveman upstream configuration.
- Exact repeated-action candidates, failure loops, classifier-derived drift, usage logs.
- Lossless JSON tool-output minification and stable task injection, no arbitrary output rewriting.
- Authority and credential executor extension contracts.

## Next: prove effectiveness

1. Runtime canary/conformance runner, tested-version matrix, OpenCode v2 adapter.
2. Real-workflow evaluations: success rate, total provider-reported tokens, cache hit rate, task latency and classifier overhead. Establish a baseline before claiming savings.
3. Validate the capability-first registry against live endpoints; measured quality, exact token/feature compatibility, live quota adapters, cost budgets and bounded escalation. Native subscription/media execution adapters remain separate from selection plans.
4. Multi-agent session lineage, better request-to-session binding and richer bounded progress summaries.

## Next: learning and deterministic tools

1. Opt-in retention of sanitized regression fixtures and semantic workflow grouping. Current candidates are exact redacted action fingerprints, not generalized workflows.
2. A bounded synthesis job proposes scripts/workflows; it does not execute or install them itself.
3. Deterministic tests, replay/shadow evaluation, human/policy approval, signed immutable tool versions and rollback.
4. Project-local promotion before client-wide promotion, no automatic relaxation of governance.

## Separate future access layer

Warden adapter, OS-managed policy distribution, workload identity, narrowly scoped capabilities, password-manager/credential injection, origin-bound browser actions, explicit legal-assent execution and enterprise audit integrations. None is implied by the local-user configuration model.
